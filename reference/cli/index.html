    CLI dos scripts¶

    Todos os comandos devem ser rodados a partir da raiz do repositório, com o .venv ativo.

    python src/ann.py¶

    Treina as cinco redes com fold_00_{train,val}.csv.

    Sem argumentos. Parâmetros editáveis no topo do arquivo:

    • MAX_EPOCHS = 1000
    • BATCH_SIZE = 1000
    • VALIDATION_FLIGHTS = ["voo-normal2", "voo-com-8-nos"]
    • HISTORY_LAGS = [5, 10, 15]
    • FOLD = 0
    • NETWORKS — grupos de entrada e coluna-alvo por rede.

    Mais em Treinar as redes.

    python src/replay.py [voo]¶

    Compara comandos previstos com o piloto, em malha aberta.

    • voo — nome do arquivo em Data/csv/voos-piloto/ sem .csv. Padrão: voo-normal3.

    Saída: terminal + artifacts/replay_<voo>.png. Ver Replay de um voo.

    python src/fly.py¶

    Autopiloto neural em malha fechada. Abre UDP 5501 (entrada do FlightGear) e envia por 5502.

    Sem argumentos. Encerra sozinho após o pouso. Log em artifacts/flights/<nome>_<timestamp>.csv.

    Pré-requisito: artifacts/*.pt + artifacts/normalization.json.

    python src/fly_pid.py¶

    Mesmo papel do fly.py, mas com PID em cascata. Lê pacotes brutos (sem filtro nem z-score). Ganhos em GAINS dentro do arquivo. Salva ganhos junto ao log em artifacts/flights/pid_<timestamp>.json.

    python scripts/fgtape_to_csv.py <entrada.fgtape> <saida.csv>¶

    Converte uma gravação binária do FlightGear em CSV. Sem dependências externas. Ver Converter fgtape.

    bash scripts/launch_flightgear.sh [wind_from] [wind_kt] [turbulence] [extra_flags...]¶

    Inicia o FlightGear (C172P, BIKF 02). Copia config/flightgear/pfe_{in,out}.xml para $FG_ROOT/Protocol/.

    Argumento Padrão Faixa
    wind_from 150 0–360 (graus)
    wind_kt 3.7 0–20 kt
    turbulence 0.0 0.0–1.0

    Variáveis de ambiente: FG_APP, FG_ROOT. Ver Launcher do FlightGear.

    bash scripts/run_flight.sh [wind_from] [wind_kt] [turbulence]¶

    Combina fly.py (ou fly_pid.py se CONTROLLER=pid) com o launcher.

    • Variável CONTROLLER: nn (padrão) ou pid.
    • Logs: artifacts/flights/, artifacts/flightgear.log.

    Ver Voar no FlightGear.
